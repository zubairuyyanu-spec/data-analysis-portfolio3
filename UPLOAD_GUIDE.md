# Upload this sample to GitHub

## Prepare the files

1. Download and extract `GitHub_Portfolio_Sample.zip` on your computer.
2. Open the extracted `sample_portfolio` folder. Review `README.md` first.
3. Create your own repository, for example `data-analysis-portfolio`. Follow the
   lab's instruction to use **Private** visibility for practice.

## Upload

1. In the repository, choose **Add file → Upload files**. For an empty repository,
   use its “uploading an existing file” link if shown.
2. Select all the files **inside** `sample_portfolio`. Keep `README.md` at the
   repository root; do not upload only the ZIP or an extra outer folder.
3. Enter a meaningful commit message, such as `Add guided sales analysis sample`.
4. Follow the available commit flow. GitHub recommends a new branch and pull
   request when uploading to the default branch. If your instructor directs a
   direct commit in this private practice repository and GitHub permits it, follow
   that lab workflow. Branch rules can change which choices are available.
5. Complete the commit or pull request and merge as appropriate. Return to the
   repository's main page and check the README, chart and file links.

If you initialized the repository with a README, the supplied README may replace
that file. Preserve any existing work before replacing it.

## Customize before presenting it as your portfolio

- Add your own introduction and explain that this was guided practice.
- Reproduce the analysis yourself and document your contribution.
- Retain the fictional-data disclosure; do not describe this as a real client project.
- Keep classroom work private unless you choose to share it. A private repository
  is only accessible to people with appropriate access.

Official upload guide (checked 6 November 2026):
https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository

created and no content has been published on your behalf.
